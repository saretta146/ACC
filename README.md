# Computational Astrophysics and Cosmology

Numerical exercises and data analysis projects developed for the **Computational Astrophysics and Cosmology** course (M.Sc. in Physics, University of Genoa).

### 1. Color-Magnitude Diagram of NGC 6397 with Gaia DR3
Gaia DR3 catalog query, kinematic field-star removal via proper motions, and Main-Sequence Turn-Off identification in Python (`astropy`, `numpy`, `matplotlib`).

### 2. The Planck PSZ2 Catalogue and the Y–M Scaling Relation
FITS catalog handling, galaxy cluster mass function estimation, and power-law calibration (Y ∝ M^α) via χ² minimization and a custom Metropolis–Hastings MCMC sampler in Python (`astropy`, `scipy`, `numpy`, `matplotlib`).

### 3. Galaxy Clustering and Power Spectrum from the Magneticum Hydrodynamical Simulation
Large-scale structure visualization, stellar mass function analysis, and 3D galaxy power spectrum P(k) & bias estimation from scratch (NGP/CIC/TSC mass-assignment schemes + FFT) in Python (`numpy`, `scipy`, `matplotlib`).

### 4. Joint Posterior (Ωₘ, H₀ r_d) from DESI BAO via MCMC
2D Metropolis–Hastings MCMC parameter estimation in flat ΛCDM using isotropic (D_V/r_d), transverse (D_M/r_d), and line-of-sight (D_H/r_d) DESI BAO observables, breaking the H₀–r_d degeneracy via Planck 2018 sound horizon calibration in Python (`numpy`, `scipy`, `matplotlib`).
